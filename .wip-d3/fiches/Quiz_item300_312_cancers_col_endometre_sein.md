- **Items indispensables** sur les messages-clés (persistance HPV oncogène ; colposcopie + biopsie ; échographie + hystéroscopie avec prélèvements) ; **aucun inacceptable** sur ces items.
- **Pièges récurrents** : CA 125, TEP et IRM en 1re intention (toujours faux) ; HPV 16 plutôt que 18 ; « l'allaitement n'est pas protecteur » ; vaccin ≠ dispense de dépistage ; frottis de contrôle différé devant une anomalie de haut grade ; confusion BRCA/Lynch (utérus = Lynch) ; erreurs de clé : HPV 18 « le plus fréquent », BRCA « autosomique récessif » (UE 9).

## c. Notions à entraîner (par priorité)

**(1) Déjà tombées**
1. HPV : persistance d'un génotype oncogène = cause du cancer du col ; HPV 16 > 18 ; HPV 6/11 = condylomes ; vaccin (garçons et filles 11-14 ans, 2 doses ; nonavalent). — rang A
2. Anomalie cytologique : HSIL/AGC/HPV+ avec LSIL-ASC-US → colposcopie + biopsie ; curetage de l'endocol pour AGC. — rang A
3. Métrorragies post-ménopausiques : cancer de l'endomètre, échographie + hystéroscopie avec biopsies (cf. quiz 43/41). — rang A
4. Sein : FdR (nulliparité, alcool, THM, ATCD familiaux) ; nodule → mammographie + échographie ; ACR 4 → biopsie ; bilan d'extension (TDM TAP + scintigraphie osseuse ou TEP-TDM) ; BRCA → sein, ovaire. — rang A pour FdR, 1re intention et biopsie

**(2) Probables, pas encore tombées**
5. Dépistage organisé du col (25-29 ans cytologie ; 30-65 ans test HPV tous les 5 ans ; HPV+ et cytologie normale → test à 12 mois ; arrêt à 65 ans) et dépistage organisé du sein (50-74 ans, mammographie bilatérale tous les 2 ans, double lecture). — rang A
6. CIN 2-3 → conisation ; type histologique ; signes (métrorragies provoquées) ; bilan IRM pelvienne ± TEP-TDM ; traitement selon le stade (chirurgie élargie / radiochimiothérapie concomitante + curiethérapie) ; séquelles.
7. Cancer de l'endomètre : FdR (obésité, diabète, œstrogènes non opposés, tamoxifène, SOPK), hyperplasie atypique → hystérectomie, facteurs pronostiques, déficit MMR / Lynch.
8. Sein : échographie seule avant 30 ans, classification ACR (0, 2, 3, 4, 5), fibroadénome, formes cliniques (Paget, inflammatoire, écoulement sérosanglant), principes du traitement (RCP, tumorectomie + radiothérapie, ganglion sentinelle, hormonothérapie), contraception et fertilité après cancer du sein, oncogénétique.
